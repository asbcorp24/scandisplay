# ScanDisplay

ScanDisplay — система фиксации экрана учебного компьютера и централизованного хранения видеозаписей по группам и студентам.

## Возможности

### Windows-клиент на C++

- работает в системном трее;
- пункты меню: **Авторизация**, **Начать запись**, **Остановить запись**, **Выход**;
- авторизация студента по индивидуальному восьмизначному цифровому коду;
- снимает весь виртуальный рабочий стол, включая несколько мониторов, один раз в секунду;
- непосредственно в каждый кадр впечатывает группу, фамилию, имя и локальное время компьютера;
- передаёт кадры в FFmpeg через pipe без временного хранения тысяч изображений;
- создаёт MP4/H.264 и после остановки отправляет файл на сервер;
- при ошибке отправки сохраняет MP4 локально для повторной обработки вручную.

### PHP-админка

- установка через браузер;
- SQLite по умолчанию или MySQL через переменные окружения;
- авторизация администратора;
- создание и переименование групп;
- создание студентов внутри групп;
- автоматическая генерация уникального цифрового кода;
- блокировка/разблокировка студента;
- перевыпуск кода с отменой старых авторизаций;
- просмотр записей по студентам и группам;
- фильтрация по датам;
- потоковое воспроизведение MP4 с поддержкой HTTP Range;
- скачивание и удаление видеозаписей;
- видео хранится вне прямой публичной выдачи и открывается через проверку административной сессии.

## 1. Требования к серверу

- PHP 8.1 или новее;
- расширения `PDO`, `mbstring`, `fileinfo`;
- `pdo_sqlite` для SQLite или `pdo_mysql` для MySQL;
- Apache 2.4 или Nginx;
- HTTPS для промышленного использования;
- право PHP на запись в `server/storage`.

Для больших видео настройте PHP, например:

```ini
upload_max_filesize = 2048M
post_max_size = 2050M
max_execution_time = 0
max_input_time = 0
memory_limit = 256M
```

Загрузка выполняется потоково, поэтому весь MP4 не помещается в память PHP.

Для Nginx дополнительно требуется, например:

```nginx
client_max_body_size 2g;
```

## 2. Установка PHP-сервера с SQLite

1. Скопируйте каталог `server` на веб-сервер.
2. Сделайте каталог `server/storage` доступным для записи пользователю веб-сервера.
3. Откройте в браузере:

```text
https://ваш-сервер/scandisplay/server/install.php
```

4. Создайте логин и пароль первого администратора.
5. После установки войдите через `index.php`.
6. Создайте группу, затем студентов.
7. Передайте каждому студенту сгенерированный цифровой код.

Файл SQLite будет создан по адресу:

```text
server/storage/database.sqlite
```

## 3. Использование MySQL

Перед запуском PHP задайте переменные окружения:

```text
SCANDISPLAY_DSN=mysql:host=127.0.0.1;dbname=scandisplay;charset=utf8mb4
SCANDISPLAY_DB_USER=scandisplay
SCANDISPLAY_DB_PASSWORD=сложный_пароль
SCANDISPLAY_TIMEZONE=Europe/Moscow
```

После этого откройте `install.php`. Установщик создаст необходимые таблицы.

Дополнительные параметры:

```text
SCANDISPLAY_UPLOAD_DIR=/srv/scandisplay-videos
SCANDISPLAY_MAX_UPLOAD_BYTES=2147483648
SCANDISPLAY_SESSION_DAYS=30
```

Рекомендуется вынести `SCANDISPLAY_UPLOAD_DIR` за пределы публичного каталога сайта.

## 4. Требования к Windows-клиенту

- Windows 10/11 x64;
- Visual Studio 2022 с компонентом **Desktop development with C++**;
- CMake 3.20 или новее;
- FFmpeg с кодировщиком `libx264`.

Проверка FFmpeg:

```powershell
C:\ffmpeg\bin\ffmpeg.exe -encoders | findstr libx264
```

## 5. Сборка клиента

```powershell
git clone https://github.com/asbcorp24/scandisplay.git
cd scandisplay
cmake -S client -B client\build -A x64
cmake --build client\build --config Release
```

Готовый файл:

```text
client\build\Release\ScanDisplay.exe
```

Также GitHub Actions формирует артефакт `ScanDisplay-Windows-x64` после успешной сборки.

## 6. Настройка клиента

Скопируйте рядом с `ScanDisplay.exe` файл:

```text
client/config.example.ini -> config.ini
```

Пример:

```ini
[server]
base_url=https://example.ru/scandisplay/server

[recording]
ffmpeg_path=C:\ffmpeg\bin\ffmpeg.exe
output_dir=%LOCALAPPDATA%\ScanDisplay\recordings
delete_after_upload=0

[client]
request_timeout_seconds=120
```

Параметр `delete_after_upload`:

- `0` — сохранять локальную копию MP4 после успешной отправки;
- `1` — удалять локальный MP4 после подтверждения сервера.

## 7. Работа пользователя

1. Запустите `ScanDisplay.exe`.
2. Значок программы появится в системном трее.
3. Откройте **Авторизация**.
4. Введите цифровой код студента.
5. После подтверждения выберите **Начать запись**.
6. Программа один раз в секунду получает кадр всего виртуального рабочего стола.
7. В верхнюю часть кадра впечатываются:
   - группа;
   - фамилия и имя;
   - текущее локальное время.
8. Выберите **Остановить запись**.
9. FFmpeg завершит MP4, после чего клиент отправит его на сервер.
10. Запись появится в админке в разделе **Видеозаписи**.

## API

### `POST /api/auth.php`

Поля формы:

```text
code
computer_name
```

При успехе сервер возвращает данные студента и случайный токен. В базе хранится только SHA-256 токена.

### `POST /api/upload.php`

Заголовок:

```text
Authorization: Bearer <token>
```

Поля `multipart/form-data`:

```text
started_at
ended_at
computer_name
video
```

## Формат записи

Клиент получает один новый кадр в секунду. Для совместимости с браузерными проигрывателями FFmpeg формирует стандартный видеопоток 25 кадров/с, повторяя кадр до появления следующего снимка. Это не повышает частоту наблюдения: фактическая частота захвата остаётся 1 кадр/с.

Звук в текущем MVP не записывается.

## Ограничения MVP

- максимальный размер одной отправки со стороны клиента — менее 4 ГБ;
- защищённый рабочий стол Windows, окно UAC и экран блокировки могут не попадать в запись;
- при завершении Windows без штатной остановки MP4 может не успеть финализироваться;
- автоматическая повторная отправка неудачных загрузок пока не реализована;
- клиент рассчитан на одного одновременно авторизованного студента на компьютере.

## Безопасность и правовые требования

- используйте только HTTPS;
- ограничьте доступ к админке;
- настройте резервное копирование базы и архива;
- установите сроки хранения и автоматическое удаление старых записей;
- заранее уведомляйте пользователей о записи экрана и получайте необходимые согласия согласно применимому законодательству и внутренним правилам организации;
- не размещайте секреты базы данных в Git.
