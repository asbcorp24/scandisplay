# ScanDisplay

Система фиксации экрана учебного компьютера и централизованного хранения записей по студентам.

Проект состоит из:

- `client/` — Windows-приложение на C++: авторизация по цифровому коду, работа из системного трея, снимок экрана раз в секунду, наложение группы/ФИО/времени, сборка MP4 и отправка на сервер.
- `server/` — PHP 8.1+ и Bootstrap: группы, студенты, цифровые коды, API авторизации и загрузки, просмотр записей.

Полная инструкция по сборке и установке добавляется вместе с исходным кодом проекта.
